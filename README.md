# Honeycomb & Heart – Coffee Shop Website

A simple coffee shop website made with HTML, CSS and JavaScript.

By **Bernardino, Ghil Jay V.**

## Pages
- `index.html` – Home page
- `Product.html` – Coffee menu with a working order cart (₱ prices)
- `login.html` – Login / Registration form with sliding animation (front-end only, no real accounts)
- `about.html` – About the project

## Other files
- `style.css`, `main.js` – Shared styles and animations (scroll reveal, rotating words, mobile menu)
- `text.py` – Jeepney passenger simulation (Python)
